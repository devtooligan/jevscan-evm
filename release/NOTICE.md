# Distribution boundaries and provenance

This directory is the standalone transaction-monitor release candidate. First-party package code and documentation are offered under the accompanying MIT license. It was extracted and hardened from the local Jevscan research implementation; the historical scores were not regenerated by the hardened code.

Do not publish the parent research repository or its Git history merely because this directory was reviewed. The parent contains private operational artifacts and a separate legacy source-code scanner. That scanner's derived third-party audit-checklist material has unresolved distribution permission and is excluded here. Raw provider responses, cache directories, spending ledgers, credentials, exploratory scripts and private review notes are also excluded.

## External material

- The label builder references the public [dawsbot/eth-labels](https://github.com/dawsbot/eth-labels) dataset at the commit recorded in `src/jevscan_monitor/labels.py`. The dataset is not bundled. Check its license and upstream terms before redistributing downloaded or derived datasets.
- RPC, explorer, price, NFT and classifier APIs retain their own access terms and data rights. This package's license does not grant permission to use or redistribute their services or responses.
- Python dependencies retain their respective licenses. The lockfiles record exact packages and hashes; installed distributions contain their license notices.
- `evidence/` contains curated transaction identifiers, incident metadata, derived numeric scores and exact detector questions. Source links and input-artifact digests are recorded in `provenance.json` and `manifest.json`. Articles, audit reports and raw provider responses are not reproduced. Source links do not imply endorsement or confirmed completeness of incident labels.

Before publishing, select a repository name, confirm ownership and the MIT copyright notice, review the detector questions, and establish a private security-reporting contact. Create the public repository from the reviewed release contents, not from the original research history.
